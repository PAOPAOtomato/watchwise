  3. ✓

    After sufficient review and trust, a matching event was downgraded at the gate without another model call or phone card.

One indoor camera setup with Frigate 0.18.2 and a 24 GB L4 on operator-managed cloud VMs. This verifies that flow, not long-term reliability, accuracy rates, or compatibility with other hardware.

What to know before connecting your cameras +

Context has limits.

The first screen may use a single event snapshot, not the whole visit. The published screener does not yet receive arming state. Memory cannot distinguish behaviors sharing a camera, label, and zone; a Real correction lowers trust but does not veto every later match.

Some checks remain open.

Clip links are implemented, but phone playback still needs a reachable Frigate URL and verification. Frigate summary ingestion passes automated tests; the live summary attempt exceeded the model’s context. Watchwise-generated summaries and additional arming/memory safeguards are being verified separately; they are not in the published installation described here.

Choose hardware with headroom.

The tested model pair exceeded 16 GB even though its profile is named nvidia-16gb. CPU profiles need careful validation, and local investigations can take substantially longer than screening. See the README for the tested setup and open checks.

◉⌂YOUR NETWORK
01 — LOCAL BY DEFAULT

Your footage stays close.

Run models on hardware you control. Optional hybrid profiles send text to a cloud model; a full cloud profile sends images and text. Telegram delivery sends alert text and, unless disabled, a snapshot through Telegram.

CPU⌘YOUR HARDWAREGPU
02 — BUILT AROUND FRIGATE

Keep the cameras you love.

Watchwise reads Frigate’s HTTP API and MQTT events. Configuration profiles exist for CPU, NVIDIA, Apple Silicon, and AMD on Linux. The live test used an L4; a profile alone does not establish hardware compatibility.

✓   Evidence collected✓   Decision recorded↳   Open to correction
03 — ALWAYS ACCOUNTABLE

Even silence has a reason.

Inspect held-back alerts and the reasoning behind each verdict. Errors and timeouts go to human review. Watchwise never writes to your Frigate installation.
